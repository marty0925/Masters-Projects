# Code from MSc 6-Month Project (Jan-Jul 2026)
## Project Title: Single-cell analysis of post-transcriptional changes underlying neurodegeneration

## Repository Structure
* **`/Originals`**: Untouched raw data (Smart-seq2 matrices).
* **`/Metadata`**: SraRunTable and extracted SRR IDs.
* **`/Scripts`**: Executable code (Numbered `00_` to `07_` in execution order).
* **`/Results`**: 
    * `/Outputs`: Intermediate tool data (Whippet, Trade-seq, PHATE, STAR alignments).
    * `/Figures`: Final plots generated during analysis (UpSet plots, Treemaps, etc.).
    * `/Tables`: Exported tabular differential expression results (.tsv/.csv).
